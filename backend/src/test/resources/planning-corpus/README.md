# Frozen planning evaluation corpus (SOV-013, FR-11, NFR-10)

Compatible, incompatible, and adversarial planning cases with the
deterministic baseline's expected recommendation. Content is frozen:
changing a case requires renaming the corpus version in
PlanningEvaluationTests, never silent edits. No country-specific
adapter may key off these fixtures; the live agent must discover
mappings through the read-only tools only.
