# `@sovra/shared`

Shared TrustMesh contracts: verification intents, candidate plans, guard
verdicts, proof requests, verification results, and the stable
machine-readable outcome-code table.

These types mirror the demo orchestration draft
(`docs/engineering/api-contract.openapi.yaml`) for the portions this slice
implements. They are not an official VC, SD-JWT, or OpenID4VP/VCI profile.
